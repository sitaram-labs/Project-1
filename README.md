# 🐍 Snake Water Gun Game

A simple Python-based Snake Water Gun game where you play against the computer.

## 🎮 How to Play

Choose one of these options:

- `s` → Snake 🐍
- `w` → Water 💧
- `g` → Gun 🔫

The computer randomly chooses one option, and the winner is decided according to the game rules.

## 🛠️ Technologies Used

- Python
- Random module

## ▶️ How to Run

1. Make sure Python is installed.
2. Open the project folder in VS Code or Git Bash.
3. Run:

```bash
python main.py
